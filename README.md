# WOOWWatches

Premium local watch & clock e-commerce frontend for Saddar, Rawalpindi.

## Included
- Men, women, boys, girls, couple, smart, mosque, wall and desk clock categories
- Search, category filters, sale filter, sorting
- Wishlist, persistent cart and local order history
- Cash-on-delivery checkout with server-side product/price validation
- Light / dark mode
- Responsive premium storefront
- Animated rotating hero offers
- Product detail pages
- Premium logo + favicon
- Toast feedback for shopping actions

## Run
```bash
npm install
npm run lint
npm run build
npm run dev
```
